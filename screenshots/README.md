# Dashboard screenshots

The `dashboard_*.jpg` files are genuine captures of the Streamlit dashboard connected to the local `olist_resume_analytics` MySQL schema. They show the overview KPIs, monthly revenue, top products, categories, order values, customer states, repeat purchasing, and RFM segments.

The dashboard replaces customer IDs with ranked display labels. Screenshots contain no credentials. Values come from the synthetic sample records shipped by the companion SQL portfolio, not from Olist's original public dataset.
